# 葡萄酒窖 · 酒款台账与窖藏批次

葡萄酒窖业务系统：管理酒款台账（按产区分组）、窖藏批次（窖藏中→可售放行）、会员（等级与积分）与销售出窖（出窖扣库存、退窖回滚）。主色酒红，左侧竖排导航，酒款按产区分组折叠。

## 模块

- **酒款 wine**：编号唯一、库存≥0、在售/停售；按产区（国产/法国/智利/澳洲/其他）与类型（红/白/起泡/甜）分组管理。
- **窖藏批次 cellar_batch**：关联酒款，批次号唯一、瓶数>0；`窖藏中 → 可售` 经 `POST /api/cellar-batches/{id}/release` 放行。
- **会员 member**：手机号唯一、积分≥0；出窖关联会员自动累加积分并按积分升级等级（普通/银卡/黑卡）。
- **销售出窖 sale_out**：引用酒款须「在售」且库存充足，新建即扣减库存、自动计算总额；`POST /api/sale-outs/{id}/refund` 退窖回滚库存（散客可不关联会员）。

## 启动

```bash
sh start.sh     # 启动 mysql / backend / frontend
sh stop.sh      # 停止
sh clean.sh     # 彻底清理（含匿名数据卷）
```
