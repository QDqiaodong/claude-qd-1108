# 葡萄酒窖 · 酒款台账与窖藏批次

葡萄酒窖业务系统：管理酒款台账（按产区分组）、窖藏批次（窖藏中→可售放行）、会员（等级与积分）与销售出窖（FEFO 批次扣库存、退窖按原批次回滚）。主色酒红，左侧竖排导航，酒款按产区分组折叠。

## 模块

- **酒款 wine**：编号唯一、在售/停售；按产区（国产/法国/智利/澳洲/其他）与类型（红/白/起泡/甜）分组管理。
  可售库存 `stock` 不由人工录入，恒等于该酒款所有「可售」批次 `available_bottles` 之和；新建酒款库存为 0，编辑页库存只读，无法绕过批次直改。
- **窖藏批次 cellar_batch**：关联酒款，批次号唯一、瓶数>0；新增字段 `available_bottles`（剩余可用瓶数）。
  - 状态机：`窖藏中 → 可售 → 已售罄`，只能逐级推进，不允许跳跃/重复。
  - `POST /api/cellar-batches/{id}/release` 放行：窖藏中 → 可售，瓶数全额计入可用瓶数并同步增加酒款库存。
  - 批次页展示每个批次窖藏中/可售/已售罄状态与可用瓶数；酒款页悬停可看多批次可用量构成。
- **会员 member**：手机号唯一、积分≥0；出窖关联会员自动累加积分并按积分升级等级（普通/银卡/黑卡），退窖对称扣回（散客不涉及积分）。
- **销售出窖 sale_out**：
  - 只有「在售且存在可售批次可用量」的酒款才能进入出窖选择；下单前预检每个明细的批次可用量，任一不足整单拒绝（无半成功）。
  - 同一酒款多个可售批次时按 **入窖日最早优先（FEFO，同日按批次 id）** 扣减，可跨批次拆扣；批次可用瓶数扣完自动置「已售罄」。
  - 每条出窖明细 `sale_out_item` 都带 `batch_id`（实际扣减批次），订单可展开查看批次来源，不允许只记酒款丢失来源。
  - 新建即扣减批次可用瓶数与酒款库存、自动计算总额；`POST /api/sale-outs/{id}/refund` 退窖时按原出窖批次逐项回补数量，已售罄批次回补后恢复「可售」，并扣回本单积分（散客不扣）。
  - 放行/出窖/退窖全程事务 + 行锁（统一按 酒款→批次 加锁顺序），拒绝状态跳跃、重复提交与并发扣超；台账库存与批次可用量不一致时给出可理解错误、只暂停该酒款并保留可继续处理的状态。

## 启动

```bash
sh start.sh     # 启动 mysql / backend / frontend
sh stop.sh      # 停止
sh clean.sh     # 彻底清理（含匿名数据卷；改了 schema 需重新构建 mysql 镜像：sh start.sh --build）
```
